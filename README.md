# Hypixel Skyblock Tools

A compilation of tools for Hypixel Skyblock hosted on [bigman7305.dev](https://bigman7305.dev). Right now, there's just one tool, but I will develop more as I find the need to.

## Tools

### Composter

> Now live at [composter.bigman7305.dev](https://composter.bigman7305.dev/)!

A tool built to calculate optimal solutions to composter upgrading. Each tab is meant to answer its own unique question.

| Tab | Question |
| --- | --- |
| Best Value Upgrades | Which upgrades give the biggest profit increase per coin spent? |
| Compost Rates | How much profit can I generate with a certain set of compost upgrades? |
| Target Uptime Upgrades | What upgrades do I need to get for my composter to run for **X** amount of time? |
| Bottom Line Upgrades | What upgrades do I need to get for my composter to be profitable? |

> **Note:** Any tab with upgrade suggestions also lists the cost of upgrading to that point, both in items and in coins.
